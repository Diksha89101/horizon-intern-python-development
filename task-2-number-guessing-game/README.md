# Number Guessing Game

A command-line number guessing game developed in Python as part of the Horizon Intern Python Development Internship.

## Features

- Three difficulty levels: Easy, Medium, and Hard
- Random number generation
- Higher and lower hints
- Limited attempts based on difficulty
- Input validation
- Attempt tracking
- Win and game-over detection
- Final game summary
- Automated unit tests using pytest

## Difficulty Levels

| Difficulty | Number Range | Maximum Attempts |
| --- | ---: | ---: |
| Easy | 1-10 | 5 |
| Medium | 1-50 | 7 |
| Hard | 1-100 | 10 |

## Requirements

- Python 3.10 or later
- pytest
