# Advanced Calculator

A command-line Advanced Calculator developed in Python as part of the Horizon Intern Python Development Virtual Internship Program.

## Features

* Basic arithmetic: addition, subtraction, multiplication, and division
* Advanced arithmetic: powers, modulus, square roots, and factorials
* Trigonometric functions: sine, cosine, and tangent using degrees
* Logarithmic functions: natural logarithm and base-10 logarithm
* Calculation history during the current session
* Input validation and error handling
* Automated tests using pytest

## Requirements

* Python 3.10 or later
* pip

## Installation

Clone the repository and navigate to this project directory.

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the calculator

```bash
python calculator.py
```

Follow the on-screen menu to select an operation.

## Run tests

```bash
python -m pytest -v
```
